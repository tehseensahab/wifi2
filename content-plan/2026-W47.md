### 1. Can Cat 6 Handle 2.5 Gbps?
- Searcher's real question: I am getting a multi-gig plan or a 2.5G router; do I have to replace the cable in my walls?
- Must contain: yes/no in sentence one; table of Cat 5e / Cat 6 / Cat 6A against 1, 2.5, 5 and 10 Gbps with the maximum length for each; how to read the jacket print; what else limits speed (ports on both ends, bad terminations, CCA cable); when it does not apply (runs over 100 m, damaged cable).
- Check first: IEEE 802.3bz (2.5GBASE-T / 5GBASE-T) summary page or the Ethernet Alliance / NBASE-T documentation for cable category and distance.
- Link to: guides/ethernet-cable-cat5e-vs-cat6-vs-cat6a, guides/do-you-need-a-multi-gig-router, guides/what-is-moca-ethernet-over-coax. Link from: the Ethernet cable guide and the multi-gig router guide.

### 2. What Is a Good Upload Speed?
- Searcher's real question: is my upload number fine for video calls, cloud backup, streaming or gaming, or do I need a different plan?
- Must contain: a number in sentence one; table of activity vs upload needed, each from the service's own requirements page (Zoom, Microsoft Teams, Twitch, a console maker); the FCC fixed-broadband benchmark with its date; typical upload by connection type only where a provider document states it; how to test; who this does not apply to (households that only stream and browse).
- Check first: FCC broadband benchmark (100/20 Mbps) in the FCC's own report or release.
- Link to: guides/why-is-my-upload-speed-slow, guides/how-much-internet-speed-do-i-need, guides/fiber-vs-cable-vs-5g-home-internet. Link from: the upload-speed troubleshooting guide and the speed guide.

### 3. 5G Home Internet vs. Cable: Which Is Better?
- Searcher's real question: T-Mobile or Verizon 5G home internet is offered at my address; should I leave cable for it?
- Must contain: verdict by need in the first paragraph; comparison table (speed range as the provider states it, upload, latency where documented, data caps, deprioritization, equipment, CGNAT and port forwarding, contracts); who should not switch (gamers hosting, port forwarding, weak signal); how to trial without cancelling cable. No prices unless verified that day on an official page.
- Check first: T-Mobile and Verizon home internet network-management or broadband-label pages for stated speed ranges and deprioritization.
- Link to: guides/fiber-vs-cable-vs-5g-home-internet, guides/best-router-for-5g-home-internet, guides/what-is-cgnat. Link from: the three-way guide (add a "5G vs cable" pointer) and the CGNAT explainer.

### 4. ASUS Smart Connect Rules Explained
- Searcher's real question: what do the Smart Connect rule settings on my ASUS router mean, and should I change them?
- Must contain: "leave defaults unless..." in sentence one; table of each rule (steering trigger, STA selection, interface select, bounce detect) with what it does in plain words; numbered steps to reach the page on current and older firmware; how to restore defaults; when to stop tuning and split the bands instead. Research-based: no invented "best" threshold values.
- Check first: ASUS FAQ 1012132 (Smart Connect) for the exact rule names and default guidance.
- Link to: guides/what-is-band-steering, guides/2-4-ghz-vs-5-ghz-vs-6-ghz-wifi, guides/wifi-keeps-disconnecting. Link from: the band steering guide (ASUS bullet).

### 5. Should I Buy My Own Modem?
- Searcher's real question: will owning a cable modem save me money, and will it work with my provider?
- Must contain: answer by situation in sentence one (only relevant on cable; fiber and 5G use provider equipment); the federal equipment-fee rule; a decision table; numbered steps (check the bill, check the approved list for your tier, buy, activate, return the rental and confirm the fee is gone); what you give up; no fee amounts unless verified that day.
- Check first: 47 U.S.C. 562 text and the provider's approved-modem page (Xfinity My Device Info).
- Link to: guides/buy-your-own-router-vs-isp-equipment, guides/docsis-3-0-vs-3-1-vs-4-0-cable-modem, guides/best-modem-for-xfinity. Link from: the router ownership guide and the DOCSIS guide. Keep this page about the modem only so it does not compete with the router page.

### 6. Wi-Fi 7 Mode: On or Off?
- Searcher's real question: my router has a "Wi-Fi 7 mode" switch; what changes if I turn it on, and will older devices break?
- Must contain: on/off answer in sentence one; what the switch changes according to the maker (security mode, MLO, channel width); table by brand of the setting name and what it controls; which devices can drop off and why; numbered steps to turn it on or off; when to leave it off.
- Check first: an official ASUS or TP-Link support page that documents a setting named "Wi-Fi 7 mode". If no maker page documents it, do not write this; use a backup.
- Link to: guides/wifi-7-mlo, guides/wifi-6e-vs-wifi-7, guides/wifi-7-not-working-windows-11. Link from: the MLO guide.

### 7. What DOCSIS Version Is My Modem? How to Check
- Searcher's real question: is the modem I already own DOCSIS 3.0 or 3.1, and is it holding back my plan?
- Must contain: fastest method in sentence one; numbered steps for each method (label and model number, maker's spec page, provider device lookup, modem status page); table of what each version means for a plan; what to do next if it is 3.0.
- Check first: a modem maker's support page on finding the model number and status page, plus Xfinity My Device Info.
- Link to: guides/docsis-3-0-vs-3-1-vs-4-0-cable-modem, guides/best-modem-for-xfinity, guides/modem-vs-router-vs-gateway. Link from: the DOCSIS guide.
