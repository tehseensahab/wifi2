2. Google port forwarding | https://support.google.com/googlehome/answer/6274503?hl=en | quotes: "Open the Google Home app." Go to Home, then Wifi, then Settings, then Advanced Networking. "Port management," then "Add." "Select the tab for the type of IP address you're forwarding." "Select a device." "When entering a port range internal and external ranges need to be the same. This is not the case for single port forwarding." "Some devices will suggest what ports to use, while others let you choose." "Choose either Transmission Control Protocol (TCP), User Datagram Protocol (UDP), or TCP/UDP." "In most cases, port forwarding (for IPv4) and port opening (for IPv6) are configured automatically" (via UPnP). Summary: if you don't know ports, contact device maker or check manual.

"Tap DHCP IP reservations," then "Add IP reservations."

ASUS FAQ 1037906 | https://www.asus.com/support/FAQ/1037906 | Last Update 2025/09/26 | applies to firmware 3.0.0.4.384.40000 and later; "WAN" > Virtual Server/Port Forwarding > [Enable Port Forwarding] ON > "Add profile"; fields "External Port," "Source IP," "Internal Port," "Internal IP Address"; quick-select list of well-known services; private WAN IP may mean multi-layer NAT and "Port Forwarding will not function properly under such environment."; "Please avoid port conflicts as they will lead to rule failures."; test: confirm LAN device opened the port, then from a PC on the internet enter router WAN IP; "If you can access the web page on the HTTP server, your port forwarding rule has been successfully set up."
